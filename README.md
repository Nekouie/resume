## About the Project
This is a personal resume website created to highlight my skills, professional experience, and projects. Built using **React**, it provides a clean and responsive interface to present my portfolio to potential employers or collaborators.

### Features
- Responsive design for desktop and mobile devices
- Sections for skills, projects, and contact information
- Deployed on GitHub Pages for easy access
